# CivicTech Waterloo Region Blog

Sharing stories, project updates, and civic tech insights from the Waterloo Region community.

🌐 **Live Site:** https://civictechwr.github.io/blog/

## About

Our blog features:
- Project updates and case studies
- Community stories and member spotlights  
- Civic tech insights and best practices
- Event recaps from our weekly hacknights

## Tech Stack

- Jekyll static site generator
- GitHub Pages hosting
- Markdown for content

## Development

```bash
bundle install
bundle exec jekyll serve --livereload  # Development server
bundle exec jekyll build               # Build for production
```
